  // D-05: pre-abort guard ← already present, do NOT remove

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller → `options.signal` | External AbortSignal controlled by caller — may fire at any time |
| `setTimeout` callback → `deadlineController.abort()` | Timer fires after effectiveDeadlineMs; abort reason is a new DOMException |
| `fetch()` throw site → catch block | fetch() throws signal.reason directly (not a new Error) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Spoofing | `classifyTransportError` — `error.name` access | mitigate | Guard `error instanceof Error ? error.name : ""` — unknown objects don't crash classification |
| T-03-07 | Denial of Service | `deadlineTimer` leak | mitigate | `clearTimeout(deadlineTimer)` in `finally` block (D-08) — fires unconditionally after fetch resolves, rejects, or body read completes |
| T-03-08 | Tampering | DOMException name — silent misclassification | mitigate | Exactly `new DOMException("Deadline exceeded", "TimeoutError")` (D-10) — test in Task 2 verifies `error.kind === "timeout"` |
| T-03-09 | Information Disclosure | `combinedSignal` in `AbortSignal.any()` | accept | Combined signal is internal to the function; not exposed to caller or response processing |
| T-03-10 | Elevation of Privilege | `AbortSignal.any([callerSignal, deadlineSignal])` | accept | Either signal aborting terminates the fetch; no privilege escalation path |
